# Product Backlog - ElevaTech

## Sprint 1: Cimientos (CI/CD, datos, módulo operativo)
- **HU-01:** Como equipo, quiero CI en la API para detectar errores antes del merge.
- **HU-02:** Como equipo, quiero CI en el portal.
- **HU-03:** Como cliente, quiero entrar con mi usuario y clave.
- **HU-04:** Como cliente, quiero que mis fallas queden registradas.
- **HU-05:** Como técnico, quiero entrar al portal y ver mis órdenes.
- **HU-06:** Como técnico, quiero registrar la inspección desde la web.
- **HU-07:** Como equipo, quiero la API y la BD desplegadas.
- **HU-08:** Como equipo, quiero artefactos Scrum base.

## Sprint 2: Portal Cliente y Watson
- **HU-09:** Como cliente, quiero un dashboard de mis órdenes.
- **HU-10:** Como cliente, quiero ver mis órdenes y equipos.
- **HU-11:** Como cliente, quiero ver el informe de inspección de mis equipos.
- **HU-12:** Como cliente, quiero reportar una falla por formulario.
- **HU-13:** Como cliente, quiero preguntar al chatbot el estado de una orden.
- **HU-14:** Como cliente, quiero que el chatbot liste mis órdenes pendientes.
- **HU-15:** Como cliente, quiero reportar una falla conversando.
- **HU-16:** Como cliente, quiero el chat dentro del portal.

## Sprint 3: Cierre, QA y entrega
- **HU-17:** Como administrador, quiero ver y atender reportes de falla.
- **HU-18:** Como equipo, quiero pruebas de integración automáticas.
- **HU-19:** Como equipo, quiero ejecutar el Plan de Pruebas y reportarlo.
- **HU-20:** Como equipo, quiero CD y endurecimiento.
- **HU-21:** Como equipo, quiero la documentación final al día.
